Warnings Disabled in Visual Studio 2015
---------------------------------------


Background Info
---------------
The library is polluted and has many many warning messages. Sigh !!!

This is being corrected horray !!! however in a phased approach. The intention is to resolve the most serious warnings first,
disabling the less severe warnings to reduce the noise in addressing the more serious warnings and bugs. Once cleaned we intend
to relax the warnings disabled and then clean the less severe warnings in a phased approach.


How to Disable Warnings
-----------------------
This is done in Visual Studio by selecting: Project Settings->C/C++->Advanced-> Disable Specific Warnings then enter the 4 digit
warning codes using the semi-colon character ';' as a delimiter to disable multiple warnings.

NOTE For the MLIB Client API Only
---------------------------------
We need to add throw(std::exception) after each function declaration to instruct SwigWin to generate Java exceptions. This syntax is deprecated in C++11 but
needed by SwigWin to generate Java exception handling code. We disable this warning in the MLIB_CLIENT_API only.
