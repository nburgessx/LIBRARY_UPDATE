Instructions
=======================
The CurveDisplay.py example loads the EUROIS and EUR3ML curves into memory from JSON file and
returns forwards and discount factors for the dates specified. The curve JSON files can
be created from Excel by creating a curve and then saving it using meLWOSave.

1) Copy the two JSON curve objects to your c:\temp folder
2) Copy the CurveDisplay.py to the Python DLL folder
3) Run the CurveDisplay.py file using IDLE
