Config File
Config.txt controls the Expiry date, which defaults to today - 1 if more than 90 days forward

Config File / Folder Location
Must place a config file on i) the same level as the example file ii) up one level in a Config folder or iii) in C:\Temp\Config.txt
e.g. ThisFolder/Config.txt, UpOneLevel/Config/Config.txt or C:\Temp\Config.txt
