## Revised disposition — NOT a Phase 1 delete

`mir` is legacy but it carries a large slice of the **flagship regression
coverage** (the yield-curve framework). Deleting it means migrating ~49 test
files to the `aq` equivalents and re-confirming every number.

**Moved to a dedicated phase after Phase 3** (see `MIGRATION_PLAN.md` "Phase 3c —
Retire `mir`"). Sequence there:

1. For each of the 22 `tryMir*` functions, identify the `tryAq*` equivalent
   (most exist: `tryMeProductSwapPV`, `tryMeProductOISParRate`,
   `tryMeCurveCalibrate*`, `tryMeDate*`, `tryMeLWOCurve*` — renamed to `tryAq*`
   in Phase 3). Record any with no equivalent → promote that one to `aq`.
2. Migrate the 49 `GOOGLE_TEST` files, re-baselining each (numbers must match).
3. Drop the `tryMir*` keys from `Replay.cpp` (the `tryMe*`→`tryAq*` keys already
   cover the four replay curves).
4. Delete: 58 `src/AQ_API/source/mir*.{cpp,h}`, 65 `src/validation/**/tryMir*.*`,
   the `mir*` blocks in the 4 `swig_*.i` (58 lines each) + `swig_R_wrap.cpp`
   (regen), and the `.vcxproj`/`.filters` entries.
5. Reword the two `mirCurveGenerate` error strings.
