
Add the declaration in the header and implementation in the cpp. Do not use namespaces or non standard types on the function signature. 
Forward the implementation to the validation_api layer.

All POD types are supported

The supported STL types are   

	std::vector<int>, 
	std::vector<std::vector<int>>,
	std::vector<double>,  
	std::vector<std::vctor<double>>, 
	std::string, 
	std::vector<std::string>, 
	std::vector<std::vector<std::string>>


Find an appropriate file/folder that adequately categorizes the function you are about to add 
(e.g. include/Date/tryDateFunctions.h and src/Date/tryDateFunctions.cpp). 
If none exists, create the folder and/or file. keep the same function signature as in the swig_*.i interface 
except add \''try\'' as a prefix to the function. Implement the function with validation of arguments.
